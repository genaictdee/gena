Notes on Building Better Web Pages

These short articles share lessons from this HTML project.

Use Link Text That Makes Sense

A link label should tell the reader what to expect. For example, “View our service guide” gives more information than a vague instruction.

View our service guide.

Describe Images According to Their Purpose

A meaningful image needs useful alternative text. A purely decorative image can use an empty alt attribute so screen readers can skip it.

Read the W3C guide to accessible images.

Give Every Form Control a Label

A visible label helps people understand what to enter. Matching the label's for attribute to the control's id also creates a programmatic connection.

Explore the labelled application form.
